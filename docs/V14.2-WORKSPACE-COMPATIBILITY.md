# V14.2：兼容官方工作空间按钮文案变更

2026-10-28（洛杉矶时间）恢复专用浏览器后，官方后台已经显示 My Workspace 的真实成员页，脚本却报“工作空间选择器不唯一或不存在”。只读探针确认当前按钮名称为：

`选择 ChatGPT 工作空间或 Ads 账户。当前选择：My Workspace，ChatGPT 工作空间`

V14.1 仅接受带“全局设置、”的旧长名称及旧短名称。缺少这几个字导致严格身份检查失败，尚未领取成员租约，也未发生邀请或移除。这次原因是官方可访问页面的文案变化，不能将其归为 Cloudflare 验证失败。

## 修复边界

只增加已观察到的新长名称：允许“全局设置、”前缀有或无。仍完整匹配配置中的工作空间名称与“ChatGPT 工作空间”类型，仍要求唯一可见按钮。保持官方 origin、工作空间 ID 路径、管理员身份、完整成员/邀请名单、已购席位容量、普通成员角色、租约及原回执校验。没有模糊匹配、私有 API、Cookie 复制或验证码处理。

V14.1 对后备轮次提前结案和 Windows 原子提交冲突的修复全部保留。正常成员操作仍由隔离桌面的普通程序执行；异常后备继续受到原有次数、期限和冻结目标限制。

## 验证与投产门槛

1. 真实新标签在原修复前必须重现失败，修复后通过；两种长标签均覆盖普通页面及模态框背景，错误工作空间、Ads 类型、重复及隐藏按钮必须拒绝。
2. 使用拦截全部网络的浏览器夹具验证邀请、撤邀、成员移除、保留付费席位及保护管理员等规则。
3. 安装后先执行隔离宿主 `admin recover-browser`，再执行 `probe`。只有新鲜完整官方观察、门户管理员身份与隔离证据通过，才启用唯一的 `NUMEMS-Agentless` 计划任务。
4. 真实待办必须取得脚本原租约、官方名单和云端完成回执。测试通过数或任务显示 Running 不能代替这项验证；没有真实成员移除待办时应明确说明尚未重新实测该分支。

Sites 云端前后端和 D1 不在本次修改范围，旧版及 TRAE 执行任务继续停用。实际测试、源码提交、安装哈希、执行器状态与业务回执另存部署报告；本文件不预先声明运行验收成功。
