# 官方后台短暂不可用的恢复机制

本修复解决两处相互独立的暂停：云端全局故障，以及本机 `ack_blocked`。
短暂验证页先自然等待就绪；超过上限且尚未领取租约/执行动作，才归类为
`browser_unavailable`。普通检查器以现有专用浏览器档案读取完整官方清单，
不会登录、点击验证码、邀请、移除、复制Cookie或调用私有成员接口。

## 恢复和边界

- 普通程序在1、2、5、15分钟后退避复查，此后最多每15分钟一次，检查不调用模型。
- 只有此专属故障可自动恢复；必须是指定Owner、工作空间及4个已购席位，
  最新完整成员/邀请快照不超过60秒，且没有未完成租约。云端重新校验并保留恢复审计。
- 云端核验时间晚于本机暂停记录时，自动解除本机 `ack_blocked`。
  已成功事件仍去重，隔离项仍锁定；未知队列结果和 `ack_uncertain` 不自动恢复。
- 已点击过成员动作但结果不明时，不能登记为此故障；保留原租约，先核对真实结果。
- Gmail只在此浏览器故障下保持独立发送；通知仍需有效30分钟窗口、独占租约、
  发件人核验和消息ID。其它全局错误、发送结果不明或未完成租约继续停止。
- 持续5分钟且至少3次只读核验失败后，仅投递一次管理员异常通知。
  同时由Codex对现有in-app会话进行一次只读恢复核验，避免专用档案暂不可用时永久卡住。
  此兜底不办理成员或邮件；获得完整官方证据后才恢复派发，仍失败则报告并等待本人处理。
  恢复后关闭该告警；下次独立故障可再通知。网页显示成员暂停及恢复状态。
- 账号登录过期、需本人完成的安全验证、角色/容量不符仍需管理员处理，
  无法承诺这些官方安全条件永远不出现。

## 验证

过期/不完整快照、未知结果保留、恢复审计、本地恢复和浏览器暂停期间邮件去重。
另需执行构建与真实只读档案验证。真实成员移除只针对现有已批准到期待办，
不得创建测试申请或伪造截止时间。上线后核对待办、回执和检查器状态。
