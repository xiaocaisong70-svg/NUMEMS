# V14 发布验收

本次升级修复邀请、回收在官方网页暂不可用时长时间等待的问题。正常操作仍由确定性脚本执行，故障后备扩展为有目标、有期限、有次数上限的成员办理。保持原站地址、员工授权和业务规则。

## 已完成的发布前验证

- 最终全量回归 640 项全部通过，无失败、跳过或取消。最初回归发现写后核对次数缩减，已恢复旧版立即核对及一秒、三秒退避，并加入共享期限；保留全部原测试断言。
- TypeScript 检查、生产构建和差异检查通过。
- 独立 owner-only 云端 D1：7 组、36 项断言，验证单次 CAS 领取、邀请/移除回执、五分钟期限、白名单撤销、未知结果原租约与凭据隔离；另通过 4 项访问/类型/参数门禁。测试使用虚构数据，不向真实成员发邀请或邮件。
- 拦截全部网络的 Edge DOM 测试覆盖邀请、撤邀、成员移除、弹窗遮挡、官方名单加载与超时。无真实登录档案或成员变化。
- 回退测试核验 V13 的全部 300 个文件，验证备份篡改、原租约未结案、模型未结束和中途文件替换失败时拒绝不安全恢复。回退不覆盖当前业务数据库。

测试报告保存在本机 `D:\codexspace\reports`：`agentless-v14-accepted-regression-20261028.log`、`agentless-v14-build-accepted-20261028.log`、`agentless-v14-hosted-d1-accepted-20261028.json`。初次受限环境的 Edge 测试启动挂起已核实为测试进程问题；未修改生产安全策略，在允许的环境重跑后通过。

## 运行契约

邀请成功须由新鲜、完整的官方成员/邀请名单确认；回收成功须目标在两份名单中均不存在，且付费席位数不变。界面点击返回、脚本退出码、模型 ACK 都不能代替官方回执。

普通浏览器操作共享 120 秒控制预算，其中写后核对共享 35 秒。门户 RPC 和落盘另有有限时限，不承诺外部网络的严格端到端 SLA。写入只执行一次；超时或响应不明保留原租约，只核对原结果。

有效待办最多每 60 秒复核。执行型后备每轮最多 3 个冻结目标，从签发起 5 分钟；同一连续故障最多 2 轮，同目标同动作最多领取一次，滚动 24 小时最多 6 轮。额度或期限耗尽在网页明确显示，不能无限唤醒。

## 发布后的核验

正式切换必须保持同一 Sites 项目、同一 My Workspace 和唯一执行器，逐文件验证本机安装，核对隐藏桌面及当前真实队列。实际成员动作只能办理当前有效申请，不生成验收申请或修改同事截止时间。生产实测结果、源提交、Sites 发布版本及 GitHub Tag 记录在相应发布清单，不把静态夹具或隔离 D1 测试冒充真实成员验收。

当所有正常授权会话都不可用，或官方明确要求本人登录、验证码或审批时，仍会安全暂停并告警。Codex 后备不等于绕过官方安全检查，也不保证永久无需人工。

详细规则见 [可靠性说明](V14-RELIABILITY.md)，回退触发条件、命令和核验方法见 [回退规程](../ROLLBACK-V14.md)。
