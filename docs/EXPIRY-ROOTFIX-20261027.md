# 到期回收根因修复

Developed by xcsong. 本说明对应 Sites 第十版。

## 问题与行为

已认领的官方操作结果不明时会暂停；此前即使后续使用原租约核实成功，全局 unknown 仍可能遗留，阻止所有后续回收。第五、六、七版均有该恢复缺口；空闲对账候选在有故障或待办时跳过，也不会替代恢复。

第十版仅为新的原操作故障保存明确来源，绑定故障 ID、原租约、申请、目标和时间。原 token 的 verified/joined 完成在同次数据库 CAS 内核验同一来源、故障未变化、完整名单安全、无其他租约或故障后，才解除本操作造成的暂停。历史缺少来源的信息不得推断自动解除。

## 其他修复

- CAS 重试重新计算相应快照时效，过期证据不能清除故障。
- 复核由嵌套四份名单减为两份完整、一致、新鲜的名单，保留中间计划和本机证据核验。
- 官方安全验证允许在原页面自然等待；不点击、伪装或绕过验证。普通加载保留原预算，验证等待有上限。
- 只保留失败阶段、固定官方路径、状态和时间等诊断，不保存 HTML、Cookie 或认证信息。
- 第八、九版的受限故障恢复、精确复核回执、提交前意图和有限退避保留。

## 真实验证与限制

85 项针对性联合回归、TypeScript 与生产构建通过，独立私有真实 D1 的 6 项合成原操作完成场景通过。D1 夹具使用合成常量及 SQL CAS 适配，不等于生产成员全链路验证。

本次三条到期申请已由管理员授权的受控浏览器流程在官方后台移除，保留原已购席位并向门户登记真实回执；不能将此记为无模型执行器已通过验收。普通后台程序仍可能被官方真人验证或登录要求阻塞。运行依赖本机在线、用户会话、网络、授权及唯一执行器；具体是否已启用应查看实时状态。

## 升级与回退

GitHub 推送不改变 Sites 部署、生产配置或计划任务。升级时先暂停后续调度并确认原动作结案，备份当前源码和配置引用；不要把其他目录的运行档案、Cookie、锁或操作日志复制进新克隆。

第十版上线前已有第九版 Sites 归档与本机原文件备份，固定 GitHub 历史可回退到 agentless-v7。回退应成对核对云端与本机代码、哈希、工作空间、管理员、调度、日志和官方名单；代码回退不撤销真实成员变更或数据库回执。未完成租约必须保留，不能靠删除锁或日志强制恢复。
